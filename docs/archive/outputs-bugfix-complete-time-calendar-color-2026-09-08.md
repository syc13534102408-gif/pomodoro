# Bug 修复交付说明:完成时间语义 + 月历底色可辨性(安卓端)

- 日期:2026-09-08
- 平台:松果 / 专注时光 · 安卓端(Flutter,`pomodoro_app/`)
- 类型:BugFix(记录时间戳语义、月历热力档位)

## 问题一:完成时间显示的是开始时间

### 现象

最近记录/记录详情里,自然完成的专注显示「完成 · 14:00」,但 14:00 实际是**开始**计时时刻(14:50 才真正完成)。

### 根因

`engine.start()` 建记录时 `at = 开始时刻`,而 `engine.complete()` 只更新了 `minutes` 与 `status`,**没有把 `at` 推进到完成瞬间**。UI(主页最近记录、详情「完成于」)一律按 `at` 渲染并冠以「完成」字样 → 标签是完成、数据是开始。这是 09-08 早些时候修复 00:00 时留下的已知遗留观察,本轮按该观察落定。

### 修复内容

| 文件 | 变更 |
|------|------|
| `pomodoro_app/lib/src/models.dart`(修改) | `FocusRecord.at` 语义注释明确:进行中=开始时刻、自然完成=完成瞬间(由引擎更新)、手动补记=用户填写时刻。`copyWith` 增加可选 `at` 参数(不传则保留原值,既有调用零影响)。 |
| `pomodoro_app/lib/src/engine.dart`(修改) | `complete()` 确认完成时 `copyWith(at: now)`,把 at 推进到真实完成时刻。`dayKey`(记录归属日)保持开始日不变,与既有「date 决定归属、at 保存时刻」序列化口径一致。 |
| `pomodoro_app/test/engine_complete_at_test.dart`(新增) | 3 个回归用例:自然完成 at=完成时刻;跨午夜完成 dayKey 不漂移且落盘往返一致;手动补记 at=用户填写时刻。 |

> UI 侧(home_page 最近记录、详情 sheet)零改动——文案本来就是「完成」语义,数据修对后即正确。
> 手动补记弹窗「完成时间」本就是用户自选时刻,`addManual` 原样存入,无此问题。

## 问题二:月历打卡底色深浅看不出

### 现象

报告页「本月回顾 → 月历打卡」标注「底色=时长 · 数字=番茄数」,但不同时长的格子底色几乎一样,区分不出深浅。

### 根因

`stats_page.dart` `_MonthGrid._level()` 的四档松绿 alpha 为 **36 / 80 / 140 / 200**,叠在米白卡 `#FFFDF8` 上:
- 最低档 α36(≈14% 松绿)与「无记录」(露卡底)几乎同色,单日 ≤30 分钟的格子像没打卡;
- 相邻档差仅 44/60/60,且多数用户单日集中在前两档(30/50/90 分钟),肉眼在 30px 小格里难以分辨。

### 修复内容

`pomodoro_app/lib/pages/stats_page.dart` `_level()` 重映射为 **α 90 / 150 / 205 / 240**,起点提升 2.5 倍保证「有记录」即可辨,档间差 ≥55 拉开深浅阶梯;白字条件保持「>180 分钟最深档」(与 α240 档对齐)。估色:α90 ≈ 淡绿(193,207,193)明显区别于卡底;α240 ≈ 深松绿(88,130,100),阶梯肉眼可辨。

## 问题三:切换专注事件后需再点其他区域才返回主界面

### 现象

主界面点「专注事件」卡唤起的选项栏(sheet),点选其他事件后只更新选中态,面板停留在原地,必须再点蒙层/其他区域才收起。

### 根因

`sheets.dart` `_TaskSheet` 的事件行 `onTap` 只 `_emit(selectedIndex)` 不收起;该 sheet 是「选择 + 管理」二合一,选中态缺少 picker 式的「选中即返回」行为。

### 修复内容

| 文件 | 变更 |
|------|------|
| `pomodoro_app/lib/src/sheets.dart`(修改) | 事件行 `onTap` 在更新 `selectedIndex` 后立即 `Navigator.pop(context)` 自动收起返回主界面;新增/重命名/改色/删除等管理操作仍在 sheet 内进行,不受影响。 |

### 验证

- `dart analyze lib/src/sheets.dart`:No issues found。
- flutter_tester 环境问题同前,建议随下轮测试一并复核。
