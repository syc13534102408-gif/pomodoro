## 1. 项目是什么

**松果 / 专注时光（Pomodoro）**：一个「本地优先」的番茄钟工具，核心诉求是**数据在自己手里、断网可用**，同时支持多设备互通。

- 本地目录：`~/Documents/Codex/2026-08-13/pinecone/`（2026-09-08 由「番茄钟」改名而来，此前为 `wo-xi`）
- 版本：`pomodoro_app` v1.1.0+3（`pubspec.yaml`）

## 2. 三端形态

| 端 | 形态 | 入口 |
|---|---|---|
| 网页版 | 原生 HTML/CSS/JS 单文件应用，部署在 GitHub Pages | `index.html` + `sw.js` |
| 安卓 App | Flutter（`pomodoro_app/`），主力机型 OPPO Find X9 Pro（arm64） | `pomodoro_app/lib/main.dart` |
| macOS 桌面版 | 与安卓共用同一套 Flutter 代码，独立桌面 UI + 菜单栏计时 | 同上（`_desktop` 分支，`home_page.dart`） |

后端服务（均无状态、无用户体系）：

| 服务 | 用途 | 技术栈 |
|---|---|---|
| 云端同步 | 网页端 ↔ 安卓端数据备份与搬运 | 腾讯云 SCF + COS（`tencent-sync/`） |
| 后台提醒 | **仅网页端** Web Push | Cloudflare Workers + Durable Objects + D1（`cloudflare-reminders/`） |

## 3. 产品目标（不可违背的既有决策）

1. **到点不自动结束**：计划时长结束后继续累计超时（`+MM:SS`），由用户点「完成」才落记录（deadline + overtime 模型）。
2. **本地优先**：所有数据存本机（localStorage / SharedPreferences），云端只做备份与搬运，断网不影响使用。
3. **同码互通**：网页端与安卓端使用同一个同步码即共享一份云端备份。
4. **第 4 个番茄进长休息**：每完成 1 次专注计 1 个番茄，每第 4 个自动进入长休息，其余进短休息；休息不产生记录。
5. **UI 仅浅色**（2026-09-07 方案 D 决定）：深色模式未设计，`main.dart` 强制 `ThemeMode.light`；视觉规格见 `docs/design/UI重构执行路径-扁平积木-2026-09-08.md`。

## 4. 功能清单（已实现，勿当作待办）

- 三种模式计时、暂停冻结剩余、继续恢复、重置丢弃（不写统计）
- 专注事件管理（增删改、配色、删除不影响历史统计）
- 今日清单（按天存储，长按可设为当前专注事件）
- 补记已完成事件；最近完成记录可删除
- 统计：今日/本周分钟、今日目标（**分钟**，旧「次」数据自动迁移）、本周目标（按次）、周堆叠柱状图（自绘）、本月回顾、连续天数、事件构成
- 云端同步：手动上传/恢复 + 自动同步（完成专注上传、回前台拉取、冲突弹窗确认）
- 提醒：安卓本地通知 + 三音提示音 + 前台服务锁屏倒计时（系统 Chronometer 渲染）；macOS 菜单栏倒计时
