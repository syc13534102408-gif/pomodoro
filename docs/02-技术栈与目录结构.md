> 按代码核对：**2026-10-25**（v1.3.11+12）。网页端已冻结，技术栈表里保留仅为对照。

## 1. 技术栈

| 端 | 技术 | 版本/说明 |
|---|---|---|
| 安卓/macOS | Flutter 3.47.1 stable，Dart 3.13.1 | SDK 在 `tools/flutter/`（项目内，不随 Git 提交） |
| 安卓构建 | Gradle Kotlin DSL + AGP 9.1.0 + Kotlin 2.4.0 + Gradle 9.3.1 | JDK 17（`tools/jdk/jdk-17.0.13.jdk`） |
| 同步后端 | 腾讯云 SCF，Node.js 18.15，128MB / 超时 20s | `tencent-sync/src/index.js`，存储用 COS |
| ~~网页版~~ | ~~原生 HTML/CSS/JS 单文件~~ | **冻结**（2026-09-02 停更，约 74KB） |
| ~~网页端提醒~~ | ~~Service Worker + Cloudflare Workers + Durable Objects + D1~~ | **冻结**（`cloudflare-reminders/`） |

### 1.1 Flutter 依赖（`pomodoro_app/pubspec.yaml`，实测）

| 包 | 用途 |
|---|---|
| `shared_preferences` | 本地持久化 |
| `intl` | 时间/数字格式化 |
| `flutter_local_notifications` + `timezone` | 本地通知 |
| `flutter_foreground_task` | 前台服务常驻（仅安卓） |
| `http` | 云端同步请求 |
| `audioplayers` | 完成提示音（`assets/sounds/`） |
| `flutter_lints`（dev） | 静态检查 |

- `dependency_overrides: path_provider_android: 2.2.23` **必须保留**：2.3.x 引入的 `jni` 原生模块会把 CMake 产物写回只读 pub 缓存导致构建失败。
- `fl_chart` 已于 2026-09-07 移除（统计图改为 `BrickBars` 自绘），**禁止重新引入**。

### 1.2 Android 构建配置（`pomodoro_app/android/app/build.gradle.kts`）

- `applicationId = com.example.pomodoro_app`（仍为模板默认值，未定制）
- `minSdk/targetSdk/compileSdk` 均取 `flutter.*` 模板默认值，未显式指定
- `versionCode/versionName` 取自 `pubspec.yaml`（当前 **11 / 1.3.10**）
- **release 使用 debug 签名**（`signingConfig = signingConfigs.getByName("debug")`）
- 开启 core library desugaring（`desugar_jdk_libs:2.1.5`），Java/Kotlin 均为 JVM 17

## 2. 目录结构

```
pinecone/
├── README.md                  # ★ 文档地图 + 快速开始（先读这个）
├── CHANGELOG.md               # 版本时间线 + bugfix 根因速记 + 后续建议
├── docs/                      # ★ 项目文档（本文档所在处）
│   ├── 01~07-*.md             # 七章权威文档
│   ├── design/                # UI 设计规格（方案 E 为现行，方案 D 为历史稿）
│   └── archive/               # 历史快照（不再维护，勿作为事实来源）
│
├── pomodoro_app/              # ★ 安卓 + macOS 共用的 Flutter 工程
│   ├── pubspec.yaml           # 依赖清单 + 版本号（v1.3.11+12）
│   ├── analysis_options.yaml  # flutter_lints 3
│   ├── lib/
│   │   ├── main.dart          # 入口：安卓初始化前台服务端口 → HomePage
│   │   ├── pages/
│   │   │   ├── home_page.dart     # 计时页（手机布局）+ macOS 桌面专注舱分支
│   │   │   ├── stats_page.dart    # 统计页（周分布 + 本月回顾 + 事件进展）
│   │   │   └── settings_page.dart # 设置页（六分区）
│   │   └── src/
│   │       ├── engine.dart        # ★ 计时状态机（纯函数）
│   │       ├── plan_import.dart   # ★ 日程解析/合并（纯 Dart，日期键按自然日）
│   │       ├── plan_remote.dart   # 智能解析客户端（POST /plan/parse，密钥在服务端）
│   │       ├── models.dart        # ★ 数据模型 + 云净荷（含 FocusEvent / Countdown）
│   │       ├── storage.dart       # 本地持久化 + 云合并（records/events 按 id 并集）
│   │       ├── cloud_sync.dart    # 云同步 HTTP 客户端
│   │       ├── cloud_auto.dart    # 自动同步：必达上传 + 节流上传 + 冲突弹窗 + 指纹
│   │       ├── notifications.dart # 本地通知 + 前台服务 + 锁屏倒计时
│   │       ├── theme.dart         # ★ 设计令牌（方案 E「松林手帐」v2）
│   │       ├── widgets.dart       # ★ 组件库（含 MinutesText 大数字+小单位）
│   │       ├── sheets.dart        # 底栏弹窗（任务/清单/日程/补记/记录详情/倒计时/事件/档案/全部记录）
│   │       └── menu_bar_timer.dart# macOS 菜单栏 + 悬浮窗状态推送
│   │   ├── android/  macos/   # 双端壳工程（macOS 侧含菜单栏 NSStatusItem、悬浮计时 NSPanel）
│   │   ├── test/              # 176 项测试 / 23 个文件（见 03）
│   │   └── tool/gen_icons.py  # 启动器图标生成脚本（Python）
│   └── build/                 # 构建产物（gitignore）
│
├── tencent-sync/              # 腾讯云同步后端（deploy.py 部署）
├── scripts/                   # 出包脚本（build-macos.sh，已入库）
├── index.html / sw.js         # 网页版（2026-09-02 起冻结，不再维护）
├── cloudflare-reminders/      # 网页端 Web Push 后端（已冻结）
├── github-pages/              # 网页版初始发布快照（仅存档）
├── work/                      # 空目录（临时工作区，未使用）
├── outputs/                   # 交付物（gitignore，不入库）
│   ├── 松果-v1.3.7-*.apk      # 安卓安装包（arm64）
│   ├── pinecore-macos-*.zip   # macOS 包（产物名 pinecore）
│   └── archive/               # 历史安装包（勿用）
│
└── tools/                     # 本机工具链（gitignore，勿删）
    ├── flutter/               # Flutter SDK 3.47.1
    ├── android-sdk/           # Android SDK（platform-tools/adb、build-tools 36.0.0）
    ├── jdk/jdk-17.0.13.jdk    # JDK 17
    └── downloads/
```

> `outputs/` 与 `tools/` 在 `.gitignore` 中，克隆仓库后不存在，需另行获取或重建工具链。
> 注意 `scripts/` 是**入库**的（与 `outputs/` 相反）——出包脚本放这里才能跟仓库走。
