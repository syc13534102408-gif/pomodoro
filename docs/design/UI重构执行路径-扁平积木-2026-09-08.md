> 面向 AI 执行者的自足式实施文档。
> 无需额外澄清即可按阶段执行；每一步给出「目标 / 输入 / 步骤 / 预期输出 / 验收」。
>
> - 目标工程：`pomodoro_app/`（Flutter，安卓为主；macOS 共用同一主题，桌面布局另有说明）
> - 参照实现：本仓库当前代码即为该设计的已实现版本（2026-09-08 核对），执行中如遇歧义，以 `lib/src/theme.dart` 与 `lib/src/widgets.dart` 为最终事实来源
> - 业务范围：**只改表现层**。`engine.dart`、`models.dart`、`storage.dart`、`cloud_sync.dart`、`cloud_auto.dart`、`notifications.dart`、`menu_bar_timer.dart` 的逻辑一律不动

## 1. 设计原则（三条铁律，任何页面不得违反）

| # | 原则 | 判定标准 |
|---|------|----------|
| 1 | **一切色块带墨色描边** | 卡片 2.5px，小元件 2.0px，分隔线 1.5px；颜色恒为 `#1A1A1A` |
| 2 | **投影只有纯色错位块** | `BoxShadow(color: ink, offset: Offset(4, 4), blurRadius: 0, spreadRadius: 0)`；**禁止**模糊阴影、渐变、发光 |
| 3 | **按压反馈唯一形式：位移消影** | 按下时色块整体 `translate(4, 4)` 并撤掉错位投影，90ms easeOut；禁用水波纹、缩放、变色 |

辅助规则：

- **阶段色语义固定**：专注 = 番茄红 `#FF765D`，短休 = 薄荷绿 `#79C7A4`，长休/目标达成 = 麦金 `#F0BC62`。
- **只有浅色一套**。深色模式未设计，强制 `Brightness.light`。
- **数字一律等宽**：计时、时长、百分比、日期数字使用 `fontFamily: 'monospace'` + `FontFeature.tabularFigures()`，防止秒数跳动引起宽度抖动。
- 触摸目标 ≥ 44dp；键盘焦点态为 3px 麦金描边；尊重系统「减弱动画」开关（开启时按压位移动画时长归零）。

## 2. 设计令牌（Design Tokens）

### 2.1 色彩

| 令牌 | 色值 | 用途 |
|------|------|------|
| `canvas` | `#FFF6E5` | 全局底色（scaffold、底栏弹窗底） |
| `card` | `#FFFFFF` | 卡片、按钮、输入框、开关轨道（关态） |
| `ink` | `#1A1A1A` | 文字、描边、错位投影，全站统一 |
| `sub` | `#6E6558` | 次级文字、说明、未选中导航 |
| `faint` | `#B9AF9C` | 禁用填充、空态占位 |
| `tomato` | `#FF765D` | 专注阶段、主按钮（起始态）、错误/删除确认 |
| `mint` | `#79C7A4` | 短休阶段、主按钮（运行中暂停）、开关开态、复选框选中 |
| `gold` | `#F0BC62` | 长休阶段、目标达成、今日高亮、焦点框、SnackBar 底 |

任务配色板 `kTaskPalette`（事件色点、统计图例，顺序固定）：

```
#FF765D  #79C7A4  #F0BC62  #9FB8D8  #C99CC0  #8FBFA8  #D9A06A  #A9AED8
```

### 2.2 几何

| 令牌 | 值 | 用途 |
|------|----|------|
| `cardBorder` | 2.5 | 卡片、对话框描边 |
| `chipBorder` | 2.0 | 按钮、开关、输入框、图例、进度条描边 |
| hairline | 1.5 | 分隔线、复选框边、今日高亮标签边 |
| `offset` | 4.0 | 错位投影位移（dx=dy=4） |
| `cardRadius` | 6.0 | 卡片、对话框圆角 |
| `chipRadius` | 4.0 | 按钮、开关、输入框圆角 |
| `tinyRadius` | 3.0 | 进度条、柱状条、分区标签、复选框圆角 |

### 2.3 字体与字号

| 场景 | 字号 | 字重 | 字体 |
|------|------|------|------|
| 计时主卡时钟 | 卡宽 × 0.30，clamp(34, 82) | w500 | monospace + tabularFigures |
| 页面大数字（周累计等） | 24–30 | w500 | monospace + tabularFigures |
| 页面标题 | 19 | w500 | 系统默认 |
| 对话框标题 | 17 | w500 | 系统默认 |
| 指标数值（MetricTile） | 17 | w500 | monospace |
| 按钮文字 | 15 | w500 | 系统默认 |
| 正文 | 14 | w400，行高 1.45 | 系统默认 |
| 副标题/输入标签 | 13 | w400–w500 | 系统默认 |
| 分区标签（墨色块内） | 12 | w500 | 系统默认 |
| 图例/说明/辅助 | 11 | w400 | 系统默认 |

字重只允许 400 / 500 两档，禁止 600+。

### 2.4 间距

| 场景 | 值 |
|------|----|
| 手机页面水平边距 | 16 |
| 页面顶部 / 底部 | 8 / 12（紧凑模式 2 / 12） |
| 区块间距（计时页） | 12–14（紧凑模式 8–10），见 §6 结构树 |
| 卡片内边距 | 14（BrickCard 默认） |
| 按钮行按钮间隔 | 10 |
| 列表行内元件间隔 | 8–12 |
| 紧凑模式触发 | 可用高度 < 720dp 时缩小间距与主卡高度 |

## 3. 分阶段执行计划

### 阶段 0：基线确认

- **目标**：确认工程处于可构建、可测试的绿色基线，记录改造前状态。
- **输入**：干净的工作区（`git status` 无未提交冲突）。
- **步骤**：
  1. `cd pomodoro_app && flutter pub get`
  2. `flutter analyze` —— 记录既有告警，后续不得新增
  3. `flutter test` —— 基线为 25 项全部通过
  4. `flutter build apk --debug` —— 确认可构建
- **预期输出**：四条命令均成功；告警清单存档备查。
- **验收**：测试 25/25 通过；构建产物生成。

### 阶段 1：`lib/src/theme.dart` —— 设计令牌与 ThemeData

- **目标**：建立唯一令牌来源，删除旧深色体系。
- **输入**：阶段 0 完成的工程。
- **步骤**：
  1. 定义 `PineColors`（按 §2.1 全量字段：`canvas/card/ink/sub/faint/tomato/mint/gold`，`line = lineStrong = ink`）。
  2. 定义 `Brick` 几何类（按 §2.2 全量字段，含 `shadow` 常量与 `box()` 通用装饰方法）。
  3. 定义 `kTaskPalette`（8 色，顺序固定）与 `kNumericFont = [FontFeature.tabularFigures()]`。
  4. 重写 `buildPineTheme()`：`Brightness.light`，scaffold 底 = `canvas`；各子主题按下表设置：

  | 子主题 | 关键设置 |
  |--------|----------|
  | `colorScheme` | light；primary=tomato，secondary=mint，tertiary=gold，surface=card，on*=ink |
  | `appBarTheme` | 底 canvas、无 elevation、标题 19/w500/ink |
  | `cardTheme` | card 底、6 圆角、2.5 墨边、无 elevation |
  | `inputDecorationTheme` | 填充 card；常态/聚焦均为 2.0 墨边、4 圆角；label 13/sub |
  | `filledButtonTheme` | tomato 底、ink 字、50 高、2.0 墨边、4 圆角 |
  | `outlinedButtonTheme` | card 底、ink 字、50 高、2.0 墨边 |
  | `dialogTheme` | card 底、6 圆角、2.5 墨边、标题 17/w500 |
  | `bottomSheetTheme` | canvas 底、顶部圆角 14 |
  | `snackBarTheme` | gold 底、ink 字、floating |
  | `switchTheme` | 开态：轨道 mint + 滑块 card；关态：轨道 card + 滑块 ink；轨道描边 2.0 墨 |
  | `checkboxTheme` | 选中 mint 填充、ink 勾、2.0 墨边、3 圆角 |
  | `dividerTheme` | ink、1.5 |
  | `timePickerTheme` | card 底、6 圆角、2.5 墨边 |

- **预期输出**：`theme.dart` 全文替换；工程中不再出现 `deep/dark/panel/raised/paper/muted` 等旧令牌。
- **验收**：`flutter analyze` 中 theme 相关零错误；`grep -r "PineColors.deep" lib/` 无结果。

### 阶段 2：`lib/src/widgets.dart` —— 积木组件库

- **目标**：提供 9 个可复用组件，各页面只组装、不自绘。
- **输入**：阶段 1 的令牌。
- **步骤**（每个组件均须实现，规格如下）：

  | # | 组件 | 规格 |
  |---|------|------|
  | 1 | `brickNumberStyle()` | 等宽数字样式工厂：monospace + tabularFigures + w500，参数 fontSize/color/weight |
  | 2 | `BrickCard` | 白底（可染色）+ 2.5 墨边 + 6 圆角 + 4px 错位投影；`onTap != null` 时整块可压（位移消影） |
  | 3 | `_BrickPressable` | 按压内核：onTapDown/Up/Cancel 驱动 `translate(4,4)` + 去投影，90ms easeOut；`disableAnimations` 时归零；键盘焦点 3px gold 边；带 Semantics(button) |
  | 4 | `BrickButton` | 默认 50 高、15/w500；`expand` 撑满或按内容收缩；纯图标时宽度=高度（正方形）；禁用=faint 填充 + sub 字；loading=18px 转圈 |
  | 5 | `BrickProgress` | 块式进度条：2.0 墨边外框（默认 14 高），内部实心色块按 ratio 截断，track 默认 card |
  | 6 | `BrickSwitch` | 轨道 50×30、2.0 墨边；开=mint 底 + card 滑块居右，关=card 底 + ink 滑块居左；滑块 20×20、2 圆角；控件外扩至 52×44 保证触摸目标；140ms 动画 |
  | 7 | `BrickTimer` | 计时主卡：底色 = 阶段色（超时/达成 = gold）；caption 13/w500 居顶；时钟 monospace 卡宽×0.30（clamp 34–82，`FittedBox` 防溢出）；底部 BrickProgress 16 高、track card、fill ink |
  | 8 | `ModeSwitcher` | 专注/短休/长休三块等宽积木（44 高，间隔 10）；选中块填阶段色，未选中 card 底；右侧 trailing 显示分钟数（11 mono） |
  | 9 | `SectionHeader` | 分区标题：墨底纸字标签块（12/w500，padding 8×3，3 圆角）+ Spacer + 可选 trailing |
  | 10 | `MetricTile` | 指标块：17 mono 数值（可染色）+ 11/sub 标签 |
  | 11 | `BrickBars` + `BrickBarSegment` | 周直方图（默认 220 高）：7 槽位，柱宽 = 槽宽×0.52，柱体按任务分段堆叠、每段独立填色 + 2.0 墨描边；基线 2.0 墨线，半高处 1.5 浅墨网格线（ink α0.18）；空日画 6px 高 faint 占位块；下方周标签，今日列用 gold 底 + 1.5 墨边小标签高亮 |
  | 12 | `formatMinutes()` | `>=60` → "X 小时 Y 分"（整小时省略分钟），否则 "N 分钟" |

- **预期输出**：`widgets.dart` 组件库完成，组件之间不互相依赖页面代码。
- **验收**：新建临时 demo 页逐挂载 9 个组件可渲染（或直接进入阶段 3 由页面验证）；`flutter analyze` 零错误。

### 阶段 7：Android 自适应图标

- **目标**：交付 Adaptive Icon 四层（背景/前景/合成/单色），松果图形 = 点阵锥形。
- **输入**：`android/app/src/main/res/`（已存在 `mipmap-anydpi-v26` 配置，需替换资源并新增单色层）。
- **步骤**：
  1. **背景层**：纯色 `#FF765D`（`drawable/ic_launcher_background.xml` 用 `<color>` 或等值 drawable）。
  2. **前景层**：108×108dp 网格（导出 432×432 px PNG，透明底），按附录 A 坐标绘制 8 枚圆点：`fill #FFF6E5` + 2.5dp 墨描边，图形整体居中且落在中央 66dp 安全区内。
  3. **单色层**（`mipmap-anydpi-v33` 的 `monochrome` 属性）：同坐标点阵，纯 `#1A1A1A` 填充、无描边，供 Android 13+ 主题图标取色。
  4. XML：

     ```xml
     <!-- mipmap-anydpi-v26/ic_launcher.xml -->
     <adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
         <background android:drawable="@drawable/ic_launcher_background" />
         <foreground android:drawable="@drawable/ic_launcher_foreground" />
         <monochrome android:drawable="@drawable/ic_launcher_monochrome" />
     </adaptive-icon>
     ```

     （v26 忽略 monochrome 属性，v33 目录下同名文件可省略 background 之外的差异；保留单一文件即可被两个版本读取。）
  5. 传统 mipmap PNG（hdpi–xxxhdpi）用合成效果（番茄红圆角方块 + 白点阵）覆盖，供旧启动器使用。
- **预期输出**：替换全部启动器图标资源。
- **验收**：`flutter build apk --release` 成功；真机安装后启动器图标为番茄红底点阵松果；开启系统主题图标（Android 13+）时变为单色取色版。
