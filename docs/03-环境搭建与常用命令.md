### 2.2 构建 APK

**可直接在工作区内构建**，无需复制到 /tmp（2026-09-08 实测；旧的「必须 /tmp」说法源于受限执行环境，已失效）：

```bash
# 全 ABI（约 53MB）
$F build apk --release

# 仅 arm64（约 19MB，推荐交付）
$F build apk --release --target-platform android-arm64
# 产物：build/app/outputs/flutter-apk/app-release.apk
```

安装到手机（USB 调试）：

```bash
tools/android-sdk/platform-tools/adb install -r pomodoro_app/build/app/outputs/flutter-apk/app-release.apk
```

### 2.3 构建 macOS 桌面版

```bash
cd pomodoro_app
export LANG=en_US.UTF-8
$F build macos --release
# 产物：build/macos/Build/Products/Release/pomodoro_app.app
# 发布命名：outputs/松果-专注时光-macos.app（zip 用 ditto -c -k --sequesterRsrc --keepParent）
```

> macOS 构建未在本轮复核。若遇删除/写入保护报错，按 `docs/archive/项目交接文档-2026-09-02.md`
> 5.5 节的 `/tmp` 副本方案回退。**Release 沙箱必须保持关闭**
> （`macos/Runner/Release.entitlements` 中 `com.apple.security.app-sandbox = false`），
> 本地 ad-hoc 签名 + 沙箱会触发 `_libsecinit_appsandbox` 崩溃。
