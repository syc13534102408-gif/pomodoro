## 设计令牌落地（`lib/src/theme.dart`）

| 令牌 | 取值 | 说明 |
|---|---|---|
| `PineColors.canvas` | `#FFF6E5` | 全局底色（米黄） |
| `PineColors.card` | `#FFFFFF` | 卡片底 |
| `PineColors.ink` | `#1A1A1A` | 文字 / 描边 / 错位投影，三合一 |

几何集中在 `Brick` 常量类：描边卡片 2.5 / 小元件 2，投影 `Brick.offset = 4`，圆角卡片 6 / 小元件 4 / 进度块 3。

旧深色令牌（`deep` / `dark` / `panel` / `raised` / `paper` / `muted`）已删除，全部调用点改名，没有留下指向浅色的别名。

## 新增基础组件（`lib/src/widgets.dart`）

- `BrickCard`：白底 + 墨描边 + 4px 纯色错位投影，可选整块点击
- `BrickButton`：按下时整体平移 4px 并撤掉投影（唯一的按压反馈）；支持图标、尾缀、纯图标正方形形态；父级宽度无界时自动退化为按内容收缩
- `BrickProgress`：外框墨描边 + 内部实心色块
- `BrickSwitch`：描边轨道 + 方形滑块，触摸目标外扩到 44px
- `BrickTimer`：计时主卡，底色随阶段切换，数字压在色块上，进度用块式条；矮卡片下数字经 `FittedBox` 自动缩小
- `BrickBars`：周直方图自绘（`CustomPainter`，按任务分色堆叠，今日列麦金标签）
- `SectionHeader`：墨色分区标签
- `brickNumberStyle()`：计时与数据统一等宽字形 + `tabularFigures`

## 页面改动（仅表现层，业务逻辑零改动）

## 本机环境备注（重要）

- 本机 Flutter SDK 在 `tools/flutter/bin/flutter`（3.47.1），不在 PATH 里
- `flutter analyze` 的 LSP 通道在本机会崩，用 `tools/flutter/bin/dart analyze` 代替，效果等价
- `flutter test` 前必须清掉代理变量，否则 `flutter_tester` 的 WebSocket 握手会被代理拦下：
  ```bash
  env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy \
      -u ALL_PROXY -u all_proxy <flutter 路径>/flutter test
  ```
- `.dart_tool/package_config.json` 曾指向重命名前的旧工作区路径，已用 `flutter pub get` 重新解析
