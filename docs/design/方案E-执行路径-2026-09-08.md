## 1. 设计原则与红线

### 1.1 视觉铁律（方向 A，任何页面不得违反）

| # | 原则 | 判定标准 |
|---|------|----------|
| V1 | 纸面分层，不靠描边 | 层次用 纸→卡 明度差（`paper`→`card`）+ 柔和投影表达；**禁止** 2px+ 描边、「全站墨边」 |
| V2 | 阶段色只做语义小面积 | 三阶段色（focus/mint/gold）只出现在：TimerPaper 顶部色条、PhaseSegments 选中浅底+实心点、进度填充、任务/记录色点、完成按钮(gold)、完成章。**禁止整卡铺阶段色** |
| V3 | 主行动恒为墨底 | 开始/暂停/继续/保存 = `ink` 实底 + `card` 色文字；「完成/完成本轮」= `gold` 实底 + `ink` 字；禁用= `faint` 填充 + `sub` 字 |
| V4 | 数字恒等宽 | 计时、时长、百分比、日期数字：mono + w600 + `FontFeature.tabularFigures()`，秒跳不抖版 |

辅助规则：

- 圆角三档：卡 20 / 控件与输入 12 / 胶囊 999 / 小元件（色条、勾选框、进度）6；列表分隔仅 hairline `line` 1px。
- 投影唯一形态：`color ink α.08, offset(0,3), blur 10`；按压时收敛（scale .97 + 阴影减淡），**允许**柔和投影与低透明度叠色，**禁止**高饱和渐变与发光。
- 触摸目标 ≥44dp；键盘焦点 = 2px `pine` 描边 + offset 2；尊重系统「减弱动画」（时长归零）。
- 只有浅色一套（D3 定稿，强制 `Brightness.light`）。

### 1.2 继承的通用规则（非方案 D 视觉专属，继续生效）

tabular 数字防抖 / 44dp 触摸 / 减弱动画归零 / 危险操作红色语义 + 确认框 / 阶段色**语义映射不变**（专注 focus、短休 mint、长休+超时 gold）/ 不引第三方图表 / 依赖只减不增 / `flutter test` 阶段回归纪律。

### 1.3 逻辑红线

1. 不改 `engine/models/storage/cloud_*/notifications/menu_bar_timer`；如需调整接口，**先停止并与需求方确认**。
2. 导航壳改造（§P3）以「不破坏现有数据流」为最低改动原则；若必须改 controller/数据持有方式，先确认再动。
3. 统计口径一律沿用现有 stats 聚合语义（`counted = status.counted || completedFlag`），不另起新口径。
4. 任务色板**顺序**与方案 D 一致（`colorIndex` 0–7 兼容老数据），只允许换色值（§2.1）。
5. 禁止新增夜间纸/深色分支（D3）。

## 3. 已核实的数据事实与统计口径（P3/P4 必读，勿臆造）

来源：`lib/src/models.dart`、`lib/src/storage.dart` 实读。

| 事实 | 结论 |
|---|---|
| 记录全量在内存 | `AppData.records: List<FocusRecord>`（全量、非分页）；月历格/周切换/记录详情均为**纯 UI 只读聚合**，无需新增逻辑接口 |
| 记录字段 | `FocusRecord`：`id / taskName / minutes(double) / dayKey('YYYY-MM-DD') / status / at / completedFlag`；`counted = status.counted \|\| completedFlag` |
| 今日目标单位 | `goalMinutes` **分钟**（默认 200）→ 今日组显示「X / Y 分钟」进度 |
| 周目标单位 | `weekGoal` **次**（默认 20）→ 报告标签「本周 N / 20 个番茄」 |
| 完成次数口径 | 「N 个番茄」= 当日/当周 `records.where(counted && dayKey∈区间).length`；累计分钟 = 同条件 `minutes` 求和 |
| 进行中记录 | 计时中 `ActiveSession.recordId` 对应的 in-progress 记录**不得**计入「最近/统计/月历」，沿用现有页面过滤语义 |
| 周边界 | 「本周」= 以周一为起点的自然周（沿用现有 stats 口径）；「上周」同理前推 7 天（D2） |
| 任务色 | `PineTask.colorIndex` → `kTaskPalette[colorIndex]`；删除任务的历史记录仅存 `taskName` 文本，展示回退 `已删除事件`（沿用 `fromMap` 语义） |

## 7. 页面布局结构树（含尺寸与间距）

### 7.1 专注页（安卓 ≤480dp 宽）

```
Scaffold(paper) → SafeArea
└─ Column
   ├─ NavigationBar(3 Tab)              // 专注/报告/设置；选中 pine
   ├─ 内容(专注子页) Padding(h20, t8)
   │  ├─ 日期行 H≈26：'9月8日 周二' 13/sub + 松果 mark 16
   │  ├─ PhaseSegments H40             // 三段等宽胶囊，间隔 8；选中=阶段 tint 底+实心点+ink 字，未选中=sub 字+line 点；trailing 分钟 mono 11
   │  ├─ gap 12
   │  ├─ 任务便签 PaperCard H56       // 10px 任务色点 + 名称 15 + chevron ›
   │  ├─ gap 14
   │  ├─ Expanded → TimerPaper(卡片)  // 顶 6px 阶段色条 → caption 12 → mono 时钟 → 6px 细进度
   │  ├─ gap 14
   │  ├─ 控制行 H46                     // [重置 ghost] [主按钮 flex ink] [完成 gold(仅运行/暂停可用/超时=完成本轮)]
   │  ├─ gap 14
   │  ├─ 今日卡(可折叠)                 // '今日' + 'X / 200 分钟 · N 个番茄'(R1) → pine 细进度 → 清单预览 ≤3 行(勾选=PaperCheck)
   │  ├─ gap 12
   │  └─ 最近记录卡(默认折叠 3 行)      // 头行 '最近记录' + '补记 +'；行=色点+任务名 14+mini 'M 分 · hh:mm' → 点击开记录详情 sheet
   └─ (紧凑 <720dp：间距 8–10；最近记录收 1 行)
```

TimerPaper 五态（控制行按 §1.1 V3 与 R2）：

| 状态 | 色条 | 时钟 | caption | 控制行 |
|---|---|---|---|---|
| 空闲 | 阶段色 | 计划时长 | 阶段名 · 任务名 | 重置 · **开始**(ink) |
| 运行 | 阶段色 | 剩余 | 第 N 个番茄 · 任务名 | 重置 · **暂停**(ink) · **完成**(gold) |
| 暂停 | 阶段色(可降 50% 透明) | 冻结剩余 | 「已暂停」前缀 | 重置 · **继续**(ink) · **完成**(gold，可用时) |
| 休息 | 短休/长休色 | 剩余 | 休息提示 | 重置 · 主按钮(依现有 engine 能力，ink) |
| 超时 | gold | `+MM:SS`(gold 字) | 「已超时 · 仍在累积」 | 重置 · **完成本轮**(gold) |
