## 3. 产品目标（不可违背的既有决策）

1. **到点不自动结束**：计划时长结束后继续累计超时（`+MM:SS`），由用户点「完成」才落记录（deadline + overtime 模型）。
2. **本地优先**：所有数据存本机（SharedPreferences），云端只做备份与搬运，断网不影响使用。
3. **同码互通**：安卓与 macOS 使用同一个同步码即共享一份云端备份（网页端已退出这条线）。
4. **休息类型按本次实际专注时长**（2026-10-09 起）：$\le 70$ 分钟 → 短休息，$>70$ 分钟 → 长休息。
   原「每第 4 个番茄进长休」的轮换已废弃——它只看次数，一次 100 分钟的长专注也只配短休。
5. **番茄以时长当量计**：每满 50 分钟 1 个番茄，缺口满 40 分钟进位（`(m+10)~/50`）。
   展示口径与休息规则都不再看"完成次数"。
6. **UI 方案 E「松林手帐」，仅浅色**（`main.dart` 强制 `ThemeMode.light`）：
   令牌权威在 `theme.dart`（v2），实施稿见 `docs/design/方案E-执行路径-2026-09-08.md`。

## 4. 功能清单（已实现，勿当作待办）

- 三种模式计时、暂停冻结剩余、继续恢复、重置丢弃（不写统计）、切换模式=挂起不打断
- **专注事件**：跨轮次的累计容器（绑定任务 + 命名），记录带 `eventId` 归属；
  改名（id 不变）、换绑任务、暂停/继续/完成、删除只解除关联；统计页「事件进展」+ 独立「事件档案」
- 任务管理（增删改、配色）、今日清单（按天存储）、补记（可选过去任意日期）
- 记录可用：全部记录清单、改时长与完成时刻、改归属事件；最近完成显示「1 小时 5 分钟」
- 统计：今日/本周、今日目标（**分钟**，旧「次」数据自动迁移）、本周目标（按次）、
  周堆叠柱状图（自绘）、本月回顾（月历打卡 + 可翻月回看）、连续天数、任务构成
- **考试倒计时**：专注页与桌面信息卡显示距考试天数，设置页可改名称/日期（仅本机，不上云）
- 云端同步：完成专注**必达上传** + 本地改动 20s 节流上传 + 回前台/3 分钟巡检拉取；
  409 冲突弹窗确认（2026-10-12 起该路径才真正可达）；恢复前自动存本机安全副本
- 会话实时同步（安卓 ↔ macOS，可选开关）：一边开始，另一边约 3 秒内同步
- 提醒：安卓本地通知 + 系统级到点闹钟 + 三音提示音 + 前台服务锁屏倒计时（系统 Chronometer 渲染）；
  macOS 菜单栏已专注时长（离屏位图渲染白字）+ 悬浮置顶计时窗（可跨全屏显示，已实机验收）
