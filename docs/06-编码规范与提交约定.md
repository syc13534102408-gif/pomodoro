# 06 编码规范与提交约定

## 1. 静态检查

- `analysis_options.yaml` → `flutter_lints: ^3.0.0`
- 检查命令：`dart analyze`（勿用 `flutter analyze`，见 03 §2.1）
- **基线**：2 条既有告警（`home_page.dart` 的 `_BrandMark.size`、`test/cloud_auto_test.dart:119`）。任何提交不得新增告警。

## 2. Dart 代码规范（从现有代码归纳）

| 规则 | 依据 |
|---|---|
| 状态机纯函数化：所有引擎操作返回新 `AppData`，不就地修改 | `engine.dart` |
| 数据类一律 `copyWith` + `toMap`/`fromMap`；"置空"字段用显式 flag（如 `clearActiveSession: true`） | `models.dart` |
| 禁止在 UI 里写裸颜色/圆角/描边值，一律引用 `PineColors.*` 与 `Brick.*` | `theme.dart` |
| 字重只用 w400/w500，禁止 600+；数字一律 `brickNumberStyle()`（monospace + tabularFigures） | `theme.dart` / `widgets.dart` |
| 私有 Widget 拆到同文件底部，命名 `_Xxx`；组件间不互相依赖页面代码 | `widgets.dart` / `home_page.dart` |
| 注释用中文，写「为什么」而不是「是什么」；关键决策处标注日期或历史原因 | 全库 |
| 平台分支集中在三处：`main.dart`、`home_page._desktop`、`notifications.ForegroundRunner.supported`，不得扩散 | 见 04 §2.3 |

## 3. UI 设计红线（方案 D「扁平积木」，违反即返工）

完整规格见 `docs/design/UI重构执行路径-扁平积木-2026-09-08.md`，速记：

1. 禁止模糊阴影、渐变、发光、玻璃拟态（`BoxShadow.blurRadius` 恒为 0）。
2. 禁止引入 `fl_chart` 等图表库（直方图由 `BrickBars` 自绘）。
3. 禁止新增深色模式分支（`ThemeMode.light` 是刻意的）。
4. 禁止修改逻辑层（engine/models/storage/cloud_*/notifications/menu_bar_timer）的逻辑；如需动接口先与需求方确认。
5. 按压反馈唯一形式：位移消影（translate 4px + 撤投影，90ms easeOut），禁水波纹/缩放/变色。
6. 页面布局树、令牌值以 `theme.dart` 与 `widgets.dart` 为最终事实来源。

## 4. 提交约定

**现状**：单人开发，`main` 分支直推（无 PR 流程）。

提交信息风格（取自近期历史）：

```
统计加本月回顾(逐日条+按事件分布)；macOS菜单栏右上角实时显示剩余时间
macOS菜单栏通道改为窗口属性持有，避免回调被释放
整理：outputs归档旧包、新增项目进度说明、交接文档同步最新状态
```

- 中文、一句话说清「改了什么 + 为什么/范围」，可用分号并列多个点
- 涉及文档时用「整理：」「文档：」前缀
- 一次提交聚焦一件事（UI/逻辑/文档分开）

**推送前检查**：

```bash
dart analyze        # 零新增告警
flutter test        # 25/25
```

**推送代理问题**：本机常驻代理（127.0.0.1:7890），push 失败时
`env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY git push origin main`。

## 5. 敏感信息

| 禁止提交 | 存放处 |
|---|---|
| 腾讯云 SecretId/Key | `~/.tencentcloud/credentials`（chmod 600） |
| VAPID 私钥 / Subject | Cloudflare Secrets（`wrangler secret put`） |
| COS 桶名等环境变量 | 函数环境变量（SCF 控制台 / `deploy.py`） |
| 同步函数 URL 快照 | `tencent-sync/.last-url`（已 gitignore） |

> 腾讯云函数环境变量必须用 `PINE_` 前缀（`TENCENTCLOUD_` 被 SCF 保留给系统变量）。
