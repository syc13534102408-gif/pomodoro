# 04 核心架构与模块职责

## 1. 总体架构

```
                    ┌──────────────── 本地优先 ────────────────┐
  网页版 index.html │ localStorage                              │ 云端 COS
  安卓  SharedPreferences ──┐  ↑↓  同步码互通                    │  sync/{code}.json
  桌面  SharedPreferences ──┤                                    │
                            ▼                                    │
                    TimerEngine（纯函数状态机）                    │
                            │ toCloudMap()                       │
                            ▼                                    │
              CloudSync (HTTP) → 腾讯云 SCF /sync/upload|download ┘
                    ↑ 冲突 409 → 弹窗，绝不静默覆盖

  旁路：安卓 ForegroundRunner/Notifier（前台服务 + 本地通知）
        桌面 MenuBarTimer → 原生 NSStatusItem 菜单栏 + FloatingTimerPanel 悬浮窗
        （两者共用一条 pine/menu_bar 通道，每秒一次，原生侧不持有计时状态）
```

分层原则：**逻辑层（engine/models/storage/cloud_*/notifications/menu_bar_timer）与表现层（theme/widgets/pages/sheets）分离**。
改 UI 不碰逻辑层；`engine.dart` 是唯一的状态变更入口（所有操作返回新 `AppData`，不就地修改）。

## 2. Flutter 端模块职责（`pomodoro_app/lib/`）

### 2.1 逻辑层

| 文件 | 职责 | 关键符号 | 依赖 |
|---|---|---|---|
| `src/engine.dart` | 计时状态机（纯函数、可单测）。超时锚点：到点后 `overtimeStartedAt` 取 `session.deadline`（而非"现在"），保证后台时间计入超时 | `TimerEngine.start/pause/resume/advance/syncMinutes/complete/discard/switchMode/addManual/restore`、`SessionView.of()`、`StatsView.of()` | `models` |
| `src/models.dart` | 全部数据模型 + 云净荷 | `SessionMode{focus,shortBreak,longBreak}`、`RecordStatus{inProgress,completed,manual,paused,interrupted}`、`PineTask/FocusRecord/TodoItem/ActiveSession/SyncState/TimerSettings/AppData`、`AppData.toCloudMap()/toMap()/copyWith()` | 无 |
| `src/storage.dart` | SharedPreferences 持久化 + 云合并 | `Storage.load/save/clear`（键 `pine-pomodoro`，兼容旧键 `pomodoro_data`）、`mergeFromCloud()`、`dateKey()` | `models` |
| `src/cloud_sync.dart` | 同步 HTTP 客户端（接口见 05） | `CloudSync.upload/download`、`CloudSync.defaultBaseUrl`（腾讯云）、`generateDeviceCode()`、`CloudSyncException{conflict}` | `http` |
| `src/cloud_auto.dart` | 自动同步策略：完成专注→上传；启动/回前台→拉取；两端都有改动→弹窗 | `AutoCloudSync.onResume/afterFocus`、`cloudFingerprint()`（剔除 id 的规范化指纹） | `models/storage/cloud_sync` |
| `src/notifications.dart` | 本地通知 + 提示音 + 安卓前台服务 + 锁屏倒计时 | `Notifier.alert/chime/cancel/requestPermission`、`ForegroundRunner.init/start/stop/supported`、`LockTimer.show`（系统 Chronometer 渲染） | `audioplayers`、`flutter_local_notifications`、`flutter_foreground_task` |
| `src/menu_bar_timer.dart` | macOS 菜单栏 + 悬浮窗的状态推导与推送（常驻显示**已专注**时长，剩余时长在下拉菜单） | `MenuBarTimer.listen/update`、`MenuBarAction{toggle,complete,discard}`、`menuBarStateOf()`、`MenuBarState{title,head,detail,tint,elapsed,progress,active}` | `engine/models` |

### 2.2 表现层

| 文件 | 职责 | 关键符号 | 依赖 |
|---|---|---|---|
| `src/theme.dart` | 设计令牌唯一来源（方案 D「扁平积木」）+ 全局 ThemeData | `PineColors`（canvas/card/ink/sub/faint/tomato/mint/gold）、`Brick`（cardBorder 2.5/chipBorder 2.0/offset 4/radius 6/4/3/hairline 1.5/shadow/box()）、`kTaskPalette`（8 色）、`kNumericFont`、`buildPineTheme()` | 无 |
| `src/widgets.dart` | 积木组件库（12 项），页面只组装、不自绘 | `brickNumberStyle()`、`BrickCard`、`BrickPressable`、`BrickButton`、`BrickProgress`、`BrickSwitch`、`BrickTimer`、`ModeSwitcher`、`SectionHeader`、`MetricTile`、`BrickBars`/`BrickBarSegment`、`formatMinutes()` | `engine/models/theme` |
| `src/sheets.dart` | 三个底栏弹窗 + 事件增删改对话框 | `showTaskSheet/showTodoSheet/showManualSheet`、`DataChanged` | `engine/models/theme/widgets` |
| `pages/home_page.dart` | 计时页（手机布局）+ macOS 桌面布局（侧边栏 + 双栏 + IndexedStack） | `HomePage`、`_controls/_metrics/_taskPicker/_recent/_header`、`_caption`（主卡五态文案） | 全部上述模块 + 两个子页面 |
| `pages/stats_page.dart` | 统计页：本周累计、每周分布（`BrickBars`）、**本月回顾**（逐日条 + 按事件分布）、事件构成 | `StatsPage`、`_MonthlyReview`、`_niceMax` | `engine/models/theme/widgets` |
| `pages/settings_page.dart` | 设置四分区：计时与目标 / 提醒 / 云端同步 / 本机数据 | `SettingsPage`、`_saveTimer/_upload/_restore/_clearRecords` | `models/storage/cloud_sync/cloud_auto/notifications/theme/widgets` |
| `main.dart` | 入口 | `PomodoroApp`（`ThemeMode.light` 强制浅色 + `buildPineTheme()`）；安卓上 `FlutterForegroundTask.initCommunicationPort()` | `home_page/theme` |

### 2.3 模块依赖方向（禁止反向）

```
models  ←  engine  ←  widgets  ←  pages/sheets
   ↑        ↑            ↑
storage  menu_bar_timer  theme
   ↑        ↑
cloud_auto, notifications
```

- `widgets.dart` 不得引用 `pages/`；`engine/models` 不得引用 Flutter Material 之外的东西（engine 保持纯 Dart 可测）。
- 唯一的平台分支点：`main.dart`（前台服务端口仅安卓）、`home_page.dart` 的 `_desktop`（macOS 布局）、`notifications.dart` 的 `ForegroundRunner.supported`（仅安卓）。

## 3. macOS 原生侧（`pomodoro_app/macos/Runner/`）

| 文件 | 职责 | 关键点 |
|---|---|---|
| `MainFlutterWindow.swift` | 主窗口 + `NSStatusItem` 菜单栏菜单 + 持有 `pine/menu_bar` 通道 | 通道必须由窗口持有（否则回调随局部变量释放）；`isReleasedWhenClosed = false`，关窗不退出 |
| `FloatingTimerPanel.swift` | 悬浮置顶计时窗（`NSPanel`）：已专注大字 + 进度条，可拖动、右键菜单 | `level = .statusBar` + `collectionBehavior = [.canJoinAllSpaces, .fullScreenAuxiliary]` → **实测可显示在全屏 App 之上**；开关与位置存 UserDefaults；无进行中会话时自动隐藏 |
| `AppDelegate.swift` | 关窗不退出、Dock 重开窗口、禁用 App Nap | `beginActivity(.userInitiated/.latencyCritical)` 令牌常驻，删掉会让后台计时被系统节流 |

三者共用同一条 `pine/menu_bar` 通道：Dart 每秒推一次状态，原生只渲染、不自己计时。

## 4. 网页端（`index.html` 单文件）

无构建步骤，文件内按区块组织。关键常量（行号为当前版本，改后以搜索为准）：

| 常量 | 值 | 说明 |
|---|---|---|
| `DEFAULT_SYNC_URL` | 腾讯云 SCF 地址 | 同步后端 |
| `DEFAULT_PUSH_WORKER_URL` | `pine-pomodoro-reminders.workers.dev` | Web Push 后端 |

配套 `sw.js`：Service Worker，接收 Web Push。

## 5. 后端服务

| 服务 | 目录 | 入口 | 部署 |
|---|---|---|---|
| 云同步（SCF） | `tencent-sync/` | `src/index.js`（Node 18，读写 COS） | `deploy.py`（Python + tencentcloud-sdk-scf） |
| Web Push（Worker） | `cloudflare-reminders/` | `src/index.js`（Durable Object `TimerReminder`） | `npm run deploy`（wrangler） |

两者接口完全一致（见 05），安卓端只连腾讯云；Cloudflare 只服务网页端推送。
