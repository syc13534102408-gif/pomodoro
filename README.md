## 功能特性

- **三种模式计时**：专注 / 短休息 / 长休息；**休息类型按本次实际专注时长决定**
  （≤70 分钟短休，>70 分钟长休，2026-10-09 起替代"每 4 次轮换"）；
  计划时长到点**不自动结束**，继续累计 `+MM:SS`，由用户点「完成」才落记录；
  计时中切换模式**不打断**——自动挂起，切回即从冻结点继续
- **番茄以时长计**：每满 50 分钟 1 个番茄（缺口满 40 分钟进位），统计日以**凌晨 3 点**为分界
- **专注事件**：跨轮次的累计容器（绑定任务 + 命名），记录带 `eventId` 归属；
  支持改名（id 不变）、换绑任务、暂停/继续/完成、删除只解除关联；
  统计页「事件进展」+ 独立「事件档案」（汇总 / 按任务构成 / 按时长排序）
- **日程（打勾清单）**：8 天排程一次粘进来就落好日期，勾选不计时；手机专注页「今日日程」卡、桌面信息卡一行
- **记录可用**：全部记录清单、改时长与完成时刻、改归属事件；最近完成显示「1 小时 5 分钟」
- **统计**：今日/本周、今日目标（分钟）与本周目标（次）、周堆叠柱状图（自绘）、
  本月回顾（月历打卡 + 可翻月回看）、连续天数、任务构成
- **考试倒计时**：专注页/桌面信息卡显示距考试天数，设置页可改名称与日期（仅本机，不上云）
- **云端同步**：完成专注**必达上传**（失败排队补传）+ 本地改动 20s 节流上传 + 回前台/巡检拉取；
  409 弹窗确认、绝不静默覆盖；恢复前自动存本机安全副本
- **会话实时同步**（安卓 ↔ macOS，可选开关）：一边开始专注，另一边约 3 秒内同步开始
- **提醒**：安卓本地通知 + 系统级到点闹钟 + 三音提示音 + 前台服务锁屏倒计时（系统 Chronometer 渲染）；
  macOS 菜单栏显示已专注时长（位图渲染白字）+ 悬浮置顶计时窗（可跨全屏显示）

## 快速开始

```bash
# 工具链在仓库内 tools/（不入库），首次需配置：
F=$PWD/tools/flutter/bin/flutter
$F config --android-sdk "$PWD/tools/android-sdk"
$F config --jdk-dir    "$PWD/tools/jdk/jdk-17.0.13.jdk"
cd pomodoro_app && $F pub get

# 日常（在 pomodoro_app/ 内）
$F --suppress-analytics test         # 157 项用例 / 20 个文件，应全绿
../tools/flutter/bin/dart analyze    # flutter analyze 的 LSP 在本机会崩，用这个
$F build apk --release --target-platform android-arm64
```

> `--suppress-analytics` 不是可有可无的：遥测日志写在 `~/.dart-tool/`，在沙箱或只读环境下
> 删除失败会让命令**在成功之后**以 exit 1 退出，容易被误判成失败。

完整命令（含 macOS 出包脚本、后端部署、装到手机）见 **[docs/03](docs/03-环境搭建与常用命令.md)**。

## 🧭 三条最高原则

1. **本地优先**：断网必须可用，云端只是备份。
2. **到点不自动结束**：超时继续累计，用户点「完成」才落记录。
3. **改 UI 不碰逻辑层**：`engine/models/storage/cloud_*/notifications/menu_bar_timer` 的逻辑不动；视觉一律引用 `theme.dart` 令牌。
