### 2.2 构建 APK

**可直接在工作区内构建**，无需复制到 /tmp（2026-09-08 实测；旧的「必须 /tmp」说法源于受限执行环境，已失效）：

```bash
# 全 ABI（约 53MB）
$F build apk --release

# 仅 arm64（约 19MB，推荐交付）
$F build apk --release --target-platform android-arm64
# 产物：build/app/outputs/flutter-apk/app-release.apk
```

安装到手机（USB 调试）：

```bash
tools/android-sdk/platform-tools/adb install -r pomodoro_app/build/app/outputs/flutter-apk/app-release.apk
```

### 2.3 构建 macOS 桌面版

macOS 构建用 `/tmp` 副本方案（2026-09-09 实测通过；工作区直构受工作区写保护影响，未验证）：

```bash
rsync -a --exclude build --exclude .dart_tool --exclude .gradle \
  ~/Documents/Codex/2026-08-13/pinecone/pomodoro_app/ /tmp/pine-macos/ && cd /tmp/pine-macos
export LANG=en_US.UTF-8
$F build macos --release
# 产物：build/macos/Build/Products/Release/pomodoro_app.app
# 归档：rsync 到 outputs/松果-专注时光-macos.app/，zip 用 ditto -c -k --sequesterRsrc --keepParent
```

> **出包后必须退出正在运行的旧进程再打开新包**——App 常驻菜单栏（关窗不退出），
> 旧进程不退会一直跑旧代码，表现为「新功能没生效」。
> **Release 沙箱必须保持关闭**（`macos/Runner/Release.entitlements` 中
> `com.apple.security.app-sandbox = false`），本地 ad-hoc 签名 + 沙箱会触发
> `_libsecinit_appsandbox` 崩溃。悬浮窗/菜单栏相关雷区见 07 §4。
